# Vasu Bhardwaj — Portfolio

Personal developer portfolio for **Vasu Bhardwaj**, a software engineer focused on backend systems, AI infrastructure, and distributed architecture.

## Live stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS + shadcn/ui
- Three.js (hero 3D scene)
- GSAP + Lenis (motion & smooth scroll)

## Sections

- Hero with WebGL background
- Skills & stats (including LeetCode activity)
- Featured projects
- Experience
- Interactive terminal (`help`, `projects`, `contact`, `resume`)
- Footer with social links

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run preview
```

## Live site (GitHub Pages)

**URL:** https://vasubhrdwj.github.io/vasu-bhardwaj-portfolio/

Pushes to `main` deploy automatically via [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

First-time setup (if Pages is not enabled yet):

1. Open **Settings → Pages** on the repo
2. Set **Source** to **GitHub Actions**

Local preview with the same base path as production:

```bash
npm run build && npm run preview
```

Then open the URL shown in the terminal (includes `/vasu-bhardwaj-portfolio/`).
